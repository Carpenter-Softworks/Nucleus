# Security

## Reporting a Vulnerability

**Please do _not_ report security vulnerabilities through public GitHub
issues.**

Instead, [report it privately](https://github.com/Carpenter-Softworks/Nucleus/security/advisories/new)
through GitHub's private vulnerability reporting on this repository.

## Supported Versions

There is no release yet, so no version is supported. Once there is one, only
the latest release will receive security fixes.
